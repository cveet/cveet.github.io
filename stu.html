命令行方法
万能密码
mythware_super_password
终止极域主程序
# Win + R → 以管理员运行 CMD taskkill /f /im StudentMain.exe
重启资源管理器
taskkill /f /im explorer /t
局域网消息轰炸
# Win + R → CMD msg /server:（目标电脑的计算机名或内网IP） * # 输入内容后 Ctrl + Z 回车发送
解除断网限制
taskkill /f /im GATESRV.exe
taskkill /f /im MasterHelper.exe
sc stop TDNetFilter
蓝屏 Taskkill（慎用）
taskkill -f -fi "pid ge 0"
注册表劫持
注册表劫持极域进程
# 运行 regedit 打开注册表编辑器，定位到：
[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\StudentMain.exe] "debugger"="cmd.exe"
# 下次极域启动时会自动打开 CMD 而非正常运行
